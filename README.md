# Decentralized Catalog Synchronization in Open E-Commerce Networks

Research project investigating decentralized edge caching and gossip-based
catalog synchronization for ONDC/Beckn-style e-commerce networks.

## Research Objective

Study whether geographically localized edge caches can reduce
discovery-plane network traffic and response latency while maintaining
bounded catalog staleness.
